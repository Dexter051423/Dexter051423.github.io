# Dexter C. de Vera Portfolio

Static portfolio site for GitHub Pages.

## Deploy with GitHub Pages

1. Create a public repository in Dexter's personal GitHub account.
2. Push this folder to the repository.
3. In GitHub, open Settings > Pages.
4. Set Source to "Deploy from a branch".
5. Choose the `main` branch and `/root`.
6. Save. The site will publish at `https://<username>.github.io/<repository-name>/`.

For a personal homepage at `https://<username>.github.io/`, name the repository exactly `<username>.github.io`.
For this signed-in account, use `Dexter051423.github.io`; the site will publish at `https://dexter051423.github.io/`.
